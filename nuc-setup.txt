1. shh to nuc: ssh-nuc
2. Install hypervisor:
sudo apt update
sudo apt install qemu-kvm libvirt-daemon-system libvirt-clients virtinst

3. Check the kvm:
ls -l /dev/kvm

4. Enable the libvirt service:
sudo systemctl enable --now libvirtd

5. Add your user to the libvirt group:
sudo usermod -aG libvirt,kvm $USER

6. List vms:
virsh list --all

7. Follow the instructions in nuc/virsh/network/notes.txt to create a network.

8. Install vagtant: Use docs

9. Setup sample m using agrant and libvirt provider. Use the following command to create a sample VM:

vagrant plugin install vagrant-libvirt


10. Edit ~/.bashrc with :-
    export VAGRANT_DEFAULT_PROVIDER=libvirt
