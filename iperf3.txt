#iperf3

MAC:
brew install iperf3

Ubuntu:
sudo apt install iperf3

Create iperf3 server on Ubuntu (NUC):
iperf3 -s -p 5201 -V

After install iperf3 on ubuntu,it may run as serice: systemctl status iperf3

Create iperf3 client on Mac:
iperf3 -c 192.168.10.2 -p 5201 -t 30 -P 8 -R -V

[ s: server, c: client, p: port, t: time, P: parallel streams, R: reverse mode, V: verbose ]
