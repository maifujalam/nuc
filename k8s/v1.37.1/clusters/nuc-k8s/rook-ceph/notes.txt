Docs: https://rook.io/docs/rook/v1.21/Helm-Charts/helm-charts/

Install Ceph Operator:
1. helm repo add rook-release https://charts.rook.io/release
2. helm repo update
3. helm show values  rook-release/rook-ceph --version v1.21.1 > values-operator.yaml
4. helm upgrade -i --create-namespace --namespace rook-ceph rook-ceph rook-release/rook-ceph --version v1.21.1 -f values-operator.yaml
5. Uninstall Ceph Operator: helm uninstall --namespace rook-ceph rook-ceph

Insall Ceph-CSI Driver:
1. helm repo add ceph-csi-operator https://ceph.github.io/ceph-csi-operator
2. helm repo update
3. helm search repo ceph-csi-operator/ceph-csi-drivers
4. helm show values ceph-csi-operator/ceph-csi-drivers --version v1.1.0 > values-ceph-csi-drivers.yaml
5. helm upgrade -i ceph-csi-drivers --namespace rook-ceph ceph-csi-operator/ceph-csi-drivers --version v1.1.0 -f values-ceph-csi-drivers.yaml
6. Uninstall Ceph-CSI Driver: helm uninstall --namespace rook-ceph ceph-csi-drivers
