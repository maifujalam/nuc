Docs: https://rook.io/docs/rook/v1.21/Helm-Charts/helm-charts/

Install Ceph Operator:
1. helm repo add rook-release https://charts.rook.io/release
2. helm repo update
3. helm show values  rook-release/rook-ceph --version v1.21.2 > values-operator.yaml
4.  Install Ceph Operator:
helm upgrade -i --create-namespace --namespace rook-ceph rook-ceph rook-release/rook-ceph --version v1.21.2 -f values-operator.yaml
5. Uninstall Ceph Operator:
helm uninstall --namespace rook-ceph rook-ceph

Insall Ceph-CSI Driver:
1. helm repo add ceph-csi-operator https://ceph.github.io/ceph-csi-operator
2. helm repo update
3. helm search repo ceph-csi-operator/ceph-csi-drivers
4. helm show values ceph-csi-operator/ceph-csi-drivers --version v1.1.0 > values-ceph-csi-drivers.yaml
5.
helm upgrade -i ceph-csi-drivers --namespace rook-ceph ceph-csi-operator/ceph-csi-drivers --version v1.1.0 -f values-ceph-csi-drivers.yaml
6. Uninstall Ceph-CSI Driver:
helm uninstall --namespace rook-ceph ceph-csi-drivers

Install Ceph Cluster[ Do not Use ArgoCD,as the order of setup is handeld by helm]:
1. helm repo add rook-release https://charts.rook.io/release [ Skip,as it already added]
2. helm repo update

3. helm show values  rook-release/rook-ceph-cluster --version v1.21.2 > values.yaml
4.  Only install via helm,managed by Argocd.
helm upgrade -i --namespace rook-ceph rook-ceph-cluster rook-release/rook-ceph-cluster --version v1.21.2 -f helm-config.yaml
5. Uninstall:

kubectl -n rook-ceph patch cephcluster rook-ceph --type merge \
  -p '{"spec":{"cleanupPolicy":{"confirmation":"yes-really-destroy-data"}}}'
kubectl -n rook-ceph delete cephcluster rook-ceph --force --grace-period=0
helm uninstall --namespace rook-ceph rook-ceph-cluster


k edit clientprofiles.csi.ceph.io -n rook-ceph rook-ceph
k delete clientprofiles.csi.ceph.io -n rook-ceph rook-ceph --force --grace-period=0

k delete ns rook-ceph --force --grace-period=0


Get Ceph FSID: kubectl -n rook-ceph get secret rook-ceph-mon -o jsonpath='{.data.fsid}' | base64 -d; echo

a. Run nuc/virsh/vms/wipe_vdb.sh from nun once to wipe disk for all vm.
