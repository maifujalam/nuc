How to create dynamic secret in vault using vault-secrets-operator?

1. Create a dynamic secret policy in vault.
For example, create a policy named `dynamic-secret-policy` with the following content:

  vault write auth/kubernetes/role/vault-operator-readonly-dynamic \
    bound_service_account_names=vault-secrets-operator \
    bound_service_account_namespaces='*' \
    token_ttl=0 \
    token_period=60 \
    token_policies=vault-operator-readonly \
    audience=vault
